# Activity image files

All activity images are stored together in this folder.

Representative previews use the suffix `-representative` before the file extension, such as `fintech-intelligent-platform-representative.jpg`. Other pictures use descriptive activity names without that suffix.

To change an activity's representative image, edit its `image` path in `activities.js` and select a file ending in `-representative`. The `activityGalleries` entries in the same file control the additional pictures shown under “My full story.”
